Sample signing assets for local testing only.

Files in this directory:

- `snp_verifier_component.private.pem`: sample Ed25519 private key
- `snp_verifier_component.public.pem`: matching sample Ed25519 public key
- `snp_verifier_component.trust-store.json`: trust store entry for the sample public key
- `snp_verifier_component.signed.wasm`: signed copy of `../snp_verifier_component.wasm` with embedded TrustMee signature expiry metadata

These assets are intentionally non-production test material.
